IS IT HONEST?

Stewart, Early Transcendentals §1.1 · p. 8–9

Briefing

Salvage lab me ek sealed box aayi hai. Andar koi machine hai — kisi ko nahi pata kaun si. Box khol nahi sakte. Sirf ek kaam kar sakte hain: input port me number daalo, output port se number pakro.

Yeh box ek ride-hailing app ka fare engine bataya jaata hai: input = distance (km), output = fare (Rs).

Mission

Pata karo ke yeh box koi bharosay ke qabil rule follow kar rahi hai ya nahi — aur "bharosay ke qabil" ka exact matlab khud dhoondo.
